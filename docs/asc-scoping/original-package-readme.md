# ASC scoping design package

Open `ASC-scoping-design.md` first. The readable starter interview is in `starter-question-bank.md`.

This is a product-design and accounting-rule authoring package, not an implemented interactive app. It contains 133 proposed questions, 28 proposed acceptance scenarios, a structural rule schema, and 14 official source records. The full authoritative ASC corpus is not included and no production rule has been certified against it.

No repository, cloud document, or live website has been modified. No automation has been scheduled.
