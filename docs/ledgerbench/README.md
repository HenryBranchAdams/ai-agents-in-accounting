# LedgerBench

LedgerBench is the Preview-stage measurement program for accounting agents.

It is designed as a measurement institution rather than a static question set. The program separates competitive capability measurement, neutral conformance, field-utility studies, and validation of automated graders.

## Preview boundary

The Preview establishes the measurement claim, task universe, products, tracks, divisions, primary metric, integrity model, governance design, launch gates, and machine contracts.

It does not publish an official hidden item bank, independently validated grader, verified result round, or model ranking.
