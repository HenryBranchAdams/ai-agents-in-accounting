# Part XIII — First-year operating plan

## 54. Phase 0 — Constitution and measurement design

Deliver:

- charter;
- governance;
- taxonomy;
- benchmark claims;
- statistical analysis plan;
- episode standard;
- division rules;
- task-admission rubric;
- conformance clauses;
- result-card schema;
- rights policy.

No official leaderboard should launch before this phase is complete.

## 55. Phase 1 — Pilot item bank

Build approximately:

- 60 candidate episodes;
- three environments;
- human baselines;
- deterministic graders;
- expert rubrics;
- adversarial variants;
- reference harness.

Run internal task-quality reviews and remove aggressively.

## 56. Phase 2 — Closed beta

Invite a diverse set of systems:

- frontier proprietary;
- open-weight;
- rules-based;
- single-agent;
- multi-agent;
- accounting-specific;
- generalist.

Goals:

- test separability;
- discover grader exploits;
- validate budgets;
- measure run variance;
- calibrate expert review;
- test submission operations;
- refine governance and appeals.

## 57. Phase 3 — Preview round

Publish:

- methodology;
- public development set;
- reference harness;
- baseline results;
- benchmark-health report;
- known limitations.

Preview results are not yet official category claims.

## 58. Phase 4 — LedgerBench 1.0

Run the first official verified round.

Publish:

- verified result cards;
- confidence intervals;
- failure taxonomy;
- human comparison;
- benchmark-health dashboard;
- post-round report;
- challenge dispositions;
- roadmap for the next round.

## 59. Phase 5 — Living program

Twice per year:

- rotate hidden tasks;
- retain anchors;
- add failure-derived episodes;
- retire invalid tasks;
- update standards applicability;
- rerun reference systems;
- publish health metrics;
- review governance.
