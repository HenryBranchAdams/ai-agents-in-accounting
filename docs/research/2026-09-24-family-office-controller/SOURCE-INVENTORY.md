# Deduplicated cumulative source inventory

The [structured inventory](source-inventory.json) contains 90 publication/edition references across the 11 controller areas. It preserves all 50 identities from the [prior family-office package](../2026-09-24-family-office-expansion/source-inventory.json). The follow-up retains reused prior research, new inspected sources, existing corpus context, and discovery or historical leads as separate observations. Reference counts describe research organization, not accounting completeness.

The five leaf packages contributed 79 observation records, many of which deliberately reuse earlier reads or canonical records. [Validation](validation.json) checks IDs, links, 11-area mapping, source keys and protected inputs. Each observation records title, publisher, original URL, edition, jurisdiction, entity role, basis, classification, supported questions, original summary, locators, verification, access, currency and rights.
