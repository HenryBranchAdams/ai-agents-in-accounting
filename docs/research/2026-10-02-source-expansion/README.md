# Source expansion — 2 October 2026

This retained research pass contains **198 new source records and 22 collections**, grouped by accounting use. Start with [SOURCES.md](SOURCES.md).

## Method

Firecrawl, Exa and Parallel Search were used for 32 retained discovery calls spanning 58 query attempts. They returned 415 result appearances, consolidated into 382 candidate URLs. Normalization handles tracking parameters, arXiv versions/mirrors, GitHub README aliases and language duplicates. Twenty-six candidates matched existing corpus URLs. Two hundred five selected pages were fetched with Parallel Search; 36 thin or ambiguous pages were rechecked with Exa. Seven selected candidates were subsequently excluded, leaving 198 additions.

Preference was given to regulators, professional bodies, original research, maintainers and official product documentation. General listicles, unverified demos, duplicate editions, secondary aggregators, broad homepages and weakly retrieved pages were omitted from the admitted set. Multiple pages from one platform are retained only when they serve distinct implementation questions.

## Files

- `SOURCES.md`: all 198 annotated links, organized into 22 categories.
- `source-additions.json` and `collection-additions.json`: exact new canonical records.
- `review.json`: review scope, original summary, access limitations, checked URL and evidence digest for each source.
- `discovery.json`: all 382 candidates and their dispositions; unselected candidates are not endorsed.
- `searches.json`: retained queries, engine and topic.
- `manifest.json`: scope, counts and repository baseline.

## Boundaries

Review was AI-assisted and limited to retrieved source sections, abstracts, schemas or landing pages. No professional accounting, legal, security or production validation is asserted. API examples were not executed. The AICPA standard received only an access-boundary check. Vendor capability descriptions, research results and authoritative requirements remain distinct. Pilot, alpha, beta, preview, historical-version and account-access restrictions are preserved in annotations. Publication and effective dates remain null unless separately established; crawler dates were not treated as publication dates.

External rights remain unknown and no third-party full text is included. An accessible repository, PDF or government URL does not establish redistribution or training permission. Source and collection metadata do not upgrade any industry's coverage to sufficient.
