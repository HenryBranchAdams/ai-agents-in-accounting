# License policy

Accounting Agents is a mixed-rights corpus. The terms named for each component control.

| Component | Grant | Applies to |
|---|---|---|
| Software | MIT | Application code, scripts, schemas, and validators |
| Original editorial content | CC-BY-4.0 | Summaries, explanatory references, workflow descriptions, and design annotations |
| Project data | CC0-1.0 | Stable IDs, project-created factual metadata, taxonomies, synthetic fixtures and reference values |
| External material | No project grant | Linked or cited publications, standards, regulations, datasets, documentation, and marks |

Catalog downloads combine metadata, editorial content, and external citations. They are not a blanket CC0 dataset. Preserve each record's `rights` and `provenance` fields. External full text is not stored. Free access, an ungated PDF, a government domain, or a DOI does not establish permission to train on or redistribute a work.

Specific record and file notices override defaults. Validly granted rights in earlier project-owned releases are not revoked. A prospective change applies only to material the project has authority to license.

The project name and branding are not licensed under MIT, CC BY, or CC0. Attribution identifies a source; it does not imply endorsement.
