# License policy

Accounting Agents is a mixed-rights distribution. The legal terms named for each component control.

| Component | Grant | Applies to |
|---|---|---|
| Software | MIT | Application code, scripts, schemas, validators, clients, CLI, and benchmark harness |
| Original content | CC-BY-4.0 | Guides, workflow explanations, annotations, rubrics, diagrams, and cleared project imagery |
| Project data | CC0-1.0 | Stable project IDs, project-created factual metadata, taxonomies, synthetic fixtures, reference values, and public numeric results |
| External material | No project grant | Linked or cited standards, regulations, papers, articles, datasets, product documentation, marks, and other third-party works |

Catalog downloads and API responses may combine CC0 metadata, CC BY annotations, and links to external material. They are mixed-rights records, not a blanket CC0 dataset. `source_rights`, `metadata_rights`, and `annotation_rights` fields identify the boundary where present. Do not infer an open license from free access, an ungated PDF, a government domain, a DOI, an API, or the word “open.”

More specific file notices and record-level rights metadata override directory defaults. Licenses already granted for a published release are not revoked. A future change applies prospectively only to material the project has authority to license.

The Accounting Agents name and branding are not licensed under MIT, CC BY, or CC0. Attribution identifies a source; it does not imply endorsement.
