# Source archive notice

The public source archive contains tracked project source, original content, generated pack artifacts, synthetic fixtures, project imagery, and non-secret deployment metadata needed by the build. Its membership is derived from an explicit source-input allowlist. It excludes Git history, generated public downloads, installed dependencies, build output, runtime caches, credentials, and the source archive itself.

The archive does not contain copies of linked external publications. Source-catalog records contain citations, access notes, rights status, and original annotations. External works remain with their publishers.

The archive is a release artifact. Verify its SHA-256 value against `downloads/SHA256SUMS` before relying on it. The canonical release manifest identifies the corpus digest and public interfaces.
